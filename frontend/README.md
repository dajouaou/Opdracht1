# WPFW Opdracht 1 – Frontend

Deze map bevat de werkende frontend van mijn portfolio.

## Bestanden

- `index.html` – Whoami
- `projecten.html` – Projecten
- `blog.html` – Blog
- `css/style.css` – centrale stylesheet

## Openen in VS Code

Open deze map als projectmap in VS Code en open `index.html` in de browser.

De drie HTML-pagina's gebruiken dezelfde stylesheet via:

`css/style.css`

De navigatie tussen Whoami, Projecten en Blog werkt met relatieve paden.
