Projecten

Een aantal projecten waar ik tijdens mijn opleiding aan heb gewerkt.

01

Java applicatie voor Dirk

Voor Dirk heb ik een Java applicatie gemaakt voor voorraadbeheer. Met de applicatie kan de voorraad makkelijker worden bijgehouden en kunnen producten overzichtelijk worden beheerd.

02

Teamflow

Teamflow is een chatapplicatie voor Scrum-teams. Berichten kunnen worden gekoppeld aan user stories, taken en epics. Zo blijft de communicatie binnen een sprint overzichtelijk.

03

Digitale veilingklok

Voor Royal FloraHolland werk ik aan een digitale veilingklok. Hiermee kunnen bloemen en planten digitaal worden geveild en tegelijkertijd aan meerdere kopers worden verkocht.

04

AI Agent voor studenten

Ik heb een AI-agent gemaakt waarmee studenten vragen kunnen stellen over hun lesstof. Kan de agent een vraag niet beantwoorden, dan kan een docent op de hoogte worden gebracht.
